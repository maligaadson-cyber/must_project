About PTMS

Project Title Management System

Project Title Management System (PTMS) is a web-based application designed to simplify the management of student project titles.

The system helps students register project titles, view available supervisors, track project status and manage project information in one centralized system.

Objectives

  • To simplify project title registration.
  • To reduce duplication of project titles.
  • To help supervisors manage student projects.
  • To improve project title tracking.
